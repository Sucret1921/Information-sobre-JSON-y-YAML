Capítulo 1

YAML

YAML (YAML Ain't Markup Language) es un formato de texto pensado para la serialización de datos, propuesto como alternativa a XML. Su sintaxis combina conceptos de varios lenguajes como HTML, C, Perl y Python.

El formato fue propuesto por Clark Evans a principios de 2001 y se dio a conocer a través de su página web yaml.org. YAML no se ha publicado como norma por ningún organismo de normalización.

Historia y versiones

  1. Enero 2004

    YAML 1.0

    Primera especificación publicada.

  2. Diciembre 2004

    YAML 1.1

    Amplía tipos y etiquetas.

  3. Octubre 2009

    YAML 1.2 Actual

    Alinea YAML con JSON: casi cualquier JSON es YAML válido.

Colecciones

Las colecciones de bloques de YAML utilizan la sangría para definir el alcance y comienzan cada entrada en su propia línea.

  • -

    Secuencias

    Cada entrada se indica con un guion y un espacio (- ).

  • :

    Mapas

    Dos puntos y un espacio (: ) separan cada par clave/valor.

  • #

    Comentarios

    Empiezan con una almohadilla u octothorpe (#), también llamado hash o signo numérico.

Consejo: usa siempre espacios para sangrar en YAML; los tabuladores no están permitidos para la indentación.
{ }

Capítulo 2

JSON

JSON (JavaScript Object Notation) es el formato de intercambio de datos que hace posible la comunicación entre aplicaciones en la web.

Se ha convertido en un formato muy popular entre los desarrolladores gracias a su texto legible por humanos, ligero, que requiere menos codificación y se procesa rápidamente.

Reglas sintácticas

Las reglas sintácticas de JSON son bastante sencillas. Existen dos tipos de elementos estructurales:

[ ]

Matrices (arrays)

Listas de valores separados por comas, escritas entre corchetes [ ].

{ }

Objetos (objects)

Listas de parejas nombre/valor separadas por comas, escritas entre llaves { }. El nombre y el valor se separan con dos puntos : y el nombre va siempre entre comillas dobles.

Los espacios en blanco y los saltos de línea no son significativos: puede haber cualquier número de ellos separando los elementos o símbolos del documento.

Tipos de datos

  • "cadena"String
  • 3.14Number
  • trueBoolean
  • nullNull
  • [ … ]Array
  • { … }Object
